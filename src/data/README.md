# Dataset goes here

Put the real **Extension of the Z-Alizadeh Sani Dataset** in this folder (`.xlsx` or `.csv`).
Download: https://doi.org/10.24432/C5461K (UCI Machine Learning Repository, CC BY 4.0).

The app loads the first `.xlsx` / `.csv` found here automatically. If the folder has no data file,
the app shows an upload screen instead. No data is generated or simulated.
